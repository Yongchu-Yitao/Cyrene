# Cyrene bundled fonts

These fonts are bundled so Cyrene uses the same glyphs and weight metrics on
macOS, Windows, and Linux. The WOFF2 files are losslessly compressed from the
upstream Google Fonts TTF files; no glyphs, hinting data, or variation tables
were removed.

| Asset | Upstream source | License |
| --- | --- | --- |
| `manrope-variable.woff2` | `google/fonts/ofl/manrope/Manrope[wght].ttf` | `OFL-Manrope.txt` |
| `noto-sans-sc-variable.woff2` | `google/fonts/ofl/notosanssc/NotoSansSC[wght].ttf` | `OFL-NotoSansSC.txt` |
| `ibm-plex-mono-regular.woff2` | `google/fonts/ofl/ibmplexmono/IBMPlexMono-Regular.ttf` | `OFL-IBMPlexMono.txt` |
| `ibm-plex-mono-medium.woff2` | `google/fonts/ofl/ibmplexmono/IBMPlexMono-Medium.ttf` | `OFL-IBMPlexMono.txt` |
| `ibm-plex-mono-semibold.woff2` | `google/fonts/ofl/ibmplexmono/IBMPlexMono-SemiBold.ttf` | `OFL-IBMPlexMono.txt` |
