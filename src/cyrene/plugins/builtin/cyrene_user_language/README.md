# 用户语言系统插件

`cyrene_user_language` 是自动加载的必需系统插件，不暴露模型工具，也无需手动挂载。
它通过 `TurnStart` Hook 在每轮系统上下文中挂载 `user_language`，要求 Agent 的
进度消息、提问、解释和最终回复使用用户在 Cyrene 中设置的语言。

每轮调用统一的 `app_language()` 解析器：优先使用应用语言设置，未设置时使用
系统语言，最终回退到英语。目前应用支持简体中文和英语。修改语言设置后，下一轮
即可生效；重新打开会话时会重新绑定同一个 Hook，不会重复注册。

用户明确要求其他语言时，按该要求指定的范围执行。代码、命令、路径、标识符和
需要精确保留的引文保持原样；工具结果和参考文档的语言不会改变回复语言。
