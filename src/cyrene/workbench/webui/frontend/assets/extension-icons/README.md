# Extension brand assets

- `python.svg`: snake paths from the [PSF logo](https://www.python.org/community/logos/), using the blue/yellow palette, with the decorative shadow omitted and a scalable viewBox. Source: https://s3.dualstack.us-east-2.amazonaws.com/pythondotorg-assets/media/files/python-logo-only.svg
- `uv.svg`: official [uv documentation logo](https://github.com/astral-sh/uv/blob/main/docs/assets/logo-letter.svg), unchanged.

- `nodejs.svg`: official [Node.js hex logo](https://nodejs.org/static/logos/nodejsHex.svg) from its branding page; SVG IDs namespaced to avoid collisions with other inline icons.

Preserve explicit SVG fills (including `none`) so outline icons and multicolor brands render correctly. Brand names and logos belong to their respective owners.
