# Android Linux 工作区休眠

移动端系统通知新增 Hibernate / 休眠。用户显式触发后，QEMU 暂停 CPU、保存完整 VM 状态，刷新磁盘，最后写入一次性恢复标记并退出 `:qemu` 进程。重新打开 App 时消费标记、恢复原后端凭据和 VM，并校正 guest 时间。切到后台仍保持任务运行，不自动休眠。

已有 raw 工作盘保留为只读 backing；新的 qcow2 overlay 存放后续写入和快照。不要删除或单独替换其中任何一个文件。快照更新只保留同名 `cyrene-resume`，避免每次退出都新增命名快照。

恢复标记绑定安装更新时间、镜像、内存和磁盘路径，且在 QEMU 启动前持久化失效。强杀、升级或恢复标记无效时从当前 overlay 冷启动，不能加载旧快照回退用户写入。保存后保持 VM 暂停直到进程退出，避免保存后又发生写入。

已验证的私有只读镜像资产记录安装版本、摘要、大小和修改时间；安装或文件变化时重新哈希，避免每次恢复重扫多个 GiB 的不变镜像。签名清单仍每次校验；缓存不用于可写用户磁盘。

首次安装、升级、异常退出仍可能慢。此实现不将 Android 后台回调当作可靠休眠时机，也不承诺恢复外部服务已经断开的网络流。活跃的远程请求可能需要重试；测试时应先让当前回复完成。

本次 APK 使用已有 beta18 签名 Debian 镜像验证 Android 管理层，没有重建 Linux 后端或改动桌面业务。`runtime-app` 与 `app` 单元测试共 26 项通过；完整 App 模拟器结果保留在 `snapshot-validation-2026-09-11`。

完整 App 验收已确认：通知休眠成功；恢复前后 Linux boot ID 相同，测试文件保留。恢复标记已消费后强杀 App，再冷启动，boot ID 改变且快照之后提交的新文件内容保留。完整 App 恢复后端耗时 17.241 秒，页面回调约 39.397 秒；这不是此前独立探针的 5 秒，尚未达到桌面就绪体验。首次安装含环境准备的后端启动约 523 秒，不能把恢复时间作为首次安装承诺。首次自动通知点击未送达服务，页面稳定后的独立点击通过；不计为保存失败。

真机并行安装：构建增加 `-PcyreneSnapshotPreview=true`，应用名为 `Cyrene Snapshot`、包名为 `ai.cyrene.mobile.snapshot`。Binder 权限随 applicationId 隔离，可与不同签名的正式版共存；不带此参数时保持原包名和名称。本次真机安装未迁移正式版数据。
