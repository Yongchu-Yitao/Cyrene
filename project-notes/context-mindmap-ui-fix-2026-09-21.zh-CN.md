# 对话上下文树界面修复与验证

## 修复

- 头部文字按钮解除原有关闭按钮的 36px 固定宽度，保持横向文本。
- 压缩统计区和工具栏；高级选项、导出、筛选收进“更多选项”。
- 提示词、记忆等运行上下文作为可展开的依赖分组，任务文档单独分组；对话问题、回复和分支成为主线。
- 分组仅用于展示，保留原始物理节点、执行顺序、各分支来源；历史上下文修订的分支末端保持可见。
- 默认视野优先对话节点，最小缩放 80%；另提供全图概览与 100% 缩放。旧版过度缩小的布局不再直接恢复。
- 没有选中节点时不占用详情侧栏；选中后自动定位，并随画布尺寸变化重新居中。
- 分支导航独立占行，不覆盖节点；修正缩放图标尺寸。窄屏详情在下方独立滚动。

## 实际界面验证

在浏览器中加载真实 `WbcContextInspectorDialog`、完整生产样式与真实上下文图接口。使用隔离 SQLite 数据，包含 7 项上下文、历史回复、修订回复与任务文档，不修改用户对话。

- 核对 1280×720、1966×1241、390×844 截图；头部按钮不竖排、不溢出。

- 实际修改记忆正文并保存为新分支，验证成功提示、修订节点、修改后正文与原分支内容。
- 窄屏选中节点实际居中，侧栏处于弹窗边界内，页面无横向溢出。
