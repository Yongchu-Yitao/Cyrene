# 消息投影优化：实现与验证

日期：2026-09-20。目标：减少长会话、较多运行消息时的前端 CPU 消耗，保持消息语义、界面和动画不变。

## 实现范围

仅在 `runtime-timeline.jsx` 的 `wbcProjectTranscript` 最后一次合并接入私有快速路径。原公共合并函数、用户消息与问答关联逻辑均保留。满足普通 JSON 数据、时间有序、assistant 增量、无关联字段且数量达到阈值时，用 Set 和双指针合并；其他输入直接回退原算法。

阈值为增量数至少 8，且 `增量数 × (历史数 + 增量数) ≥ 4096`。校验不排序、不改写输入、不增加跨渲染缓存，保留消息对象引用及同时间的稳定顺序。没有修改渲染组件、CSS、动画、调度、协议、工具权限或模型配置。构建产物已更新。

此结论针对本次修改。工作区同时存在其他任务的界面、session 插件等变动；没有覆盖或回滚这些变动。实验保留了实施前原文件，并用冻结的同一份前端依赖分别构建旧算法和新算法。

## 等价性验证

新增 6 项正式前端测试：

- 10,000 个固定种子差分案例，包含实际快速路径命中及回退；逐项比较原算法输出、对象引用和不可变输入。
- 相同时间、重复及空 ID、旧时间字段、非法时间、乱序、稀疏数组、getter、特殊原型、用户/问答/乐观消息等边界。
- 120 个事件版本，每个重放两次，比较两版本完整投影；另外覆盖 checkpoint、删除、完成、取消、失败和重连状态。

真实生产 WbcMain 会话组件的浏览器实验完成 29 个状态检查，全部一致，快速路径实际命中 26 次。比较内容包含 DOM HTML、文本、逐元素布局与样式、消息节点复用、输入内容与选区、滚动位置、文本选择和回调。

检查了流式增量、停留在历史位置时不跳到底部、选择文字后更新、工具详情展开、复制、编辑及取消、深浅色、中英文、双会话组件、切换会话、重连标记、删除、重试清除及三类终态。增加了非空断言，确保编辑框、展开按钮、复制回调、滚动与节点数量确实发生预期变化。

47 组动画采样在两版本间完全一致：比较时长、延迟、缓动、关键帧，以及 0%、25%、50%、75%、100% 的计算 opacity/transform。包括流式淡入和重试清除。动画用 Web Animations API 暂停并采样；这不是实时 FPS 或所有设备逐帧录屏证明。

实验适配器开发过程中出现过缺少运行时字段、双 iframe 抢焦点、外部输入和不同自然时钟偏移等问题，全部保留在原始日志中；最终通过记录由 `browser-summary.json` 的 runId 标识。焦点检查在真实增量更新前后同步执行，随后立即失焦，避免外部输入；没有改动产品聚焦逻辑。语言检查主动触发相同的根组件更新。双栏使用两个真实 WbcMain，不等于完整外壳分屏控制器的端到端测试。

## 性能实验

同机、同份输入，交替运行旧/新算法，测量完整 `wbcProjectTranscript`。Node 每组丢弃 3 次预热并保留 21 次；浏览器按 AB/BA 交替三轮、每轮每组 7 次。以下均为中位数，单位 ms。

| 历史 + 运行消息数 | Node 旧 → 新 | 浏览器旧 → 新 |
|---|---:|---:|
| 100 + 1 | 0.0318 → 0.0322 | 均低于计时分辨率，不计算倍率 |
| 1000 + 1 | 0.1952 → 0.1979 | 0.20 → 0.20 |
| 1000 + 40 | 3.9427 → 0.2806 | 4.40 → 0.30 |
| 1000 + 1000 | 137.2796 → 0.6682 | 148.80 → 0.70 |
| 5000 + 40 | 19.3812 → 1.4708 | 未测 |
| 5000 + 1000 | 509.4602 → 1.9409 | 未测 |

小增量保留原路径；大批量有序消息显著减少同步计算。数据只代表本机消息投影阶段，不能解释成模型推理、工具执行或完整 agent 总时长提升同样倍数。本次未新增真实低配设备、多操作系统或网络端到端测量。

## 回归结果及已知失败

- 前端全套：178 通过，0 失败；最后复测亦通过。
- Electron Node 测试：138 通过，0 失败。不是启动各平台 Electron GUI 的测试。
- 生产构建：通过。
- Python 首轮全量：3163 通过、5 跳过、5 失败，115.31 秒。
- Python 失败相关文件复测：29 通过、2 失败；最终再复测结果相同。

剩余失败是 `test_private_cross_package_imports_can_only_decrease` 和 `test_private_domain_and_sibling_plugin_imports_cannot_grow`。日志指向另一个正在编辑的 `cyrene_sessions` 插件跨模块私有导入（包括 `_chat_application_port`），并非本次 JS 合并改动。没有修改测试基线来消除这些失败，也没有将其写作全套通过。首轮其他三项插件清单/翻译失败在并发工作区后续状态下复测通过。
