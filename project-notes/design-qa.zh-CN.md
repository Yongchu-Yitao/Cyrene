# 浏览器浮窗设计验收——交互打磨

## 对照目标

- 对象是 Electron 原生浏览器在对话中的浮窗、最大化和最小化状态。
- 参考图路径保留在英文记录中。
- 修订后的拖动、缩放和全屏往返状态尚无同视口最终截图；当时由用户执行真实
  Electron 交互验收。

## 结论

- **P1：仍需新的拖动/缩放运行时证据。** 最新实现会在交互期间隐藏原生
  `WebContentsView`，在壳内显示页面截图代理，并在指针释放后于最终边界重新
  挂接原生页面。静态源码审查不能证明时间顺序完全正确。
- **P1：仍需新的全屏 → 浮窗合成器恢复证据。** 原生视图在切换期间保持挂接但
  隐藏，隐藏时调整最终尺寸，显示后立即及 80ms 后重绘；仍需真实往返确认不白屏。
- 浮窗与最大化标题使用绿色 `浏览器` pill；最大化栏高 58px。
- 默认浮窗 280 × 215px，可在 240 × 180px 到对话内容区域之间调整；最小化是
  单一 40px 绿色 pill。
- 操作期间使用当前页面自身的 PNG 截图代理；全屏恢复使用 Material
  `close_fullscreen` 图标，没有伪造网页内容。

## 关键修订

1. 文字窗口按钮改为有无障碍标签的 SVG 图标，并让原生页面边界同步浮窗。
2. Electron 35 的高频 `setBounds` 改为渲染端去重、主进程 32ms 稳定合并。
3. 拖动/缩放改为 pointer capture + 截图代理，释放后再恢复原生视图。
4. 统一 20px/16px 外内圆角、下边距和阴影，最终最小化状态只保留绿色 pill。
5. 全屏双向切换保持原生视图 attached-but-hidden，并在最终尺寸预渲染完成前保留代理。
6. 初始尺寸由 560 × 430px 减半；移动和缩放边界统一到对话内容的 inset 矩形。

## 验证

- 历史自动验证：`npm run build`；
  `pytest -q tests/test_workbench_frontend_logic.py`（100 passed）；
  `pytest -q tests/test_browser_session.py`（58 passed）；
  `node --check electron/main.js`；`node --check electron/preload.js`；
  `git diff --check`。
- 当时 Electron 已在 `127.0.0.1:4242` 启动。
- 最新进程中的拖动、缩放、最大化、恢复、最小化和重新打开仍列为待人工验证。

# 文献库设计验收

## 对照目标

- 最终对照视口为 Cyrene Electron 1313 × 768；深色选中条目用于主对照，浅色
  用于验证主题。
- 数据是当前项目的 26 条真实知识文档，没有复制参考图中的示例记录。
- 全量参考、实现和聚焦对比曾用于当次本机验收，2026-07-26 在保留本节结论
  后删除。

## 结论

- 没有遗留可执行的 P0、P1 或 P2 视觉差异。
- 采用 13–24px 的 Workbench 字体层级；分类栏 196px、检查器 260px，中间列表
  自适应且无横向滚动。
- 深海军蓝只作用于深色主题；浅色保持中性表面。标签使用透明描边，洋红只用于
  主操作和活动指示。
- `我的知识库`、`我的收藏夹`、`标签云` 可折叠并保持当前范围。
- Zotero 和 Embedding 使用 General settings 的标准平面字段布局；Zotero
  只从设置页导入当前项目。
- 内容来自当前项目隔离数据库；只有来源元数据明确提供的 abstract 才显示为摘要，
  生成描述和索引正文不会冒充原文摘要。
- 下方详情可垂直调整、高度不超过中心区 50%；左右列独立滚动。完整元数据编辑在
  右侧检查器底部，删除操作在检查器页签最右侧。
- 表头固定、表体独立滚动；详情打开时仍可到达最后一条。表格和卡片选择态都使用
  轻强调填充与细描边。
- 引用标题和复制菜单同一基线，可复制纯文本或 BibTeX；引用项使用完整 1px
  主题色轮廓，没有单独左边条。
- `内容` 优先显示原附件：图片内嵌，音视频原生播放，PDF 内嵌，其他二进制提供
  打开入口；Markdown 转为经过清理的语义 HTML。
- 切换条目或进入内容页签会回到顶部。

## 修订历史摘要

1. 完成项目隔离 Library、旧文档兼容、Zotero、Embedding 和 Agent 检索。
2. 收紧面板、字体和表格列，消除中心横向滚动。
3. 修正明暗主题作用域、分类栏底色、折叠组和标题/分隔线。
4. 将 Zotero 导入集中到设置页，并统一标签、页签与设置字段样式。
5. 重做元数据、来源摘要、可调整详情区、引用菜单、独立滚动和选择态。
6. 把列表表体与固定表头/详情区分离，验证可滚动到最后一项。
7. 将内容页从纯索引文本扩展到附件感知渲染和安全 Markdown。
