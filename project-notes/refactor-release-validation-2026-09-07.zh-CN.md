## 真实运行发现并修复的问题

1. **视觉探测图片损坏**：原 PNG 在 Pillow 像素解码时报 `broken data stream`，导致多家真实供应商拒绝。替换为有效 128×128 PNG，保留请求/能力判定流程；原测试由只查 data URL 前缀加强为 Base64 解码、PNG verify、像素 load。相关 Python 65 项通过。
2. **浏览器计时上报 400**：实际请求混入服务器阶段，10 项超过接口上限 8 项；基线真实接口也返回 `stages/too_long`。上传边界只投影接口支持的四个客户端阶段，本地完整时间线不删减。新增行为测试以实际十阶段输入验证四阶段上传及原输入保留。五项相关 JS 测试、构建和复杂度检查通过。真实浏览器调用修复后的公共 Chat Model 上报同样的十阶段输入，真实接口返回 200/ok，本地仍保留十阶段。自然聊天的上报时机受运行状态影响，额外一次等待自动上报超时，未将其计作自动上报通过。

因此四项缺口中，提交/CI与独立审查已经补齐；真实服务和性能验证已显著扩展，但受配置与运行环境限制，不能声称“所有供应商组合、所有平台、全场景性能全部验收完成”。
